# 0006 — 아이템 표기: `/give` 문법

2026-09-23 · 두 번째 이야기 조각 1 · 고치는 비용: **비쌈** (`quests.json`에 남는다)

> 이름 변경(2026-09-24, [0007](0007-rename-lorebench.md)): 이 기록의 Colophon·`colophon`은 지금 Lorebench·`lorebench`다(노드 id `lorebench:…`, 명령어 `/lorebench`, 폴더 `config/lorebench` 등).

## 결정

퀘스트 보상 아이템은 **`/give` 명령어가 쓰는 문법 한 줄**로 적는다.

```json
"rewards": [ { "item": "minecraft:iron_sword[custom_name='\"대장장이의 칼\"',enchantments={levels:{'minecraft:sharpness':2}}]", "count": 1 } ]
```

- `minecraft:wheat`는 이 문법의 가장 짧은 꼴이라 옛 퀘스트가 그대로 통한다. **형식 번호는 1 그대로.**
- 마인크래프트의 파서(`ItemParser`)로 읽는다. 1.21에서 아이템에 붙는 정보는 모두 "컴포넌트"이고, 파서는 등록된 컴포넌트 목록 전체에서 찾으니 **다른 모드의 인챈트·컴포넌트도 된다**(예: Gobber의 `gobber2:boolean_component_type`).
- 반대로 아이템을 이 문법으로 쓰는 기능(`ItemInput.serialize`)도 있다. 나중의 "들고 있는 아이템 가져오기"가 이 한 줄을 만들어 줄 수 있다.
- publish와 서버 시작 때 이 게임의 레지스트리로 읽어 본다. 못 읽으면(오타, 빠진 모드, 바뀐 컴포넌트) 파서의 오류 메시지와 함께 거부한다.
- 아이콘은 아이템 id만.

## 제출형 목표: `/clear` 문법 (작가 도구 조각, 같은 날 추가)

```json
"goals": [ { "item": "minecraft:iron_sword[custom_data={colophon:'smith_sword'}]", "count": 1 } ]
```

- 목표 아이템은 **`/clear`·`/execute if items`가 읽는 아이템 조건**으로 적는다(`ItemPredicateArgument`). 모양은 `/give`와 같지만 뜻이 다르다: **적힌 컴포넌트만 같으면 인정, 적히지 않은 것은 무시.** `#minecraft:logs`(태그), `!`(아님), `|`(또는)도 된다. `minecraft:wheat`는 예전처럼 "밀이면 무엇이든".
- 진행 표시·제출 가능·회수가 모두 같은 조건으로 센다(서버와 화면이 같은 코드).
- 엄격함은 **적는 것으로** 조절한다. 이름만 적으면 느슨하고, 인챈트까지 적으면 더 엄격하다. **위조를 막으려면 숨은 표식**: 보상에 `custom_data={colophon:'…'}`를 붙이고 목표에 같은 표식을 적는다. 생존 모드 플레이어는 `custom_data`를 만들 수 없어서, 모루로 이름만 바꾼 가짜는 인정되지 않고 닳거나 이름이 바뀐 진짜는 인정된다.
- "모든 것이 완전히 같아야 인정"은 만들지 않았다. 내구도 때문에 진짜도 떨어지고, 표식이 위조 방지를 더 잘 한다. 표식으로 풀 수 없는 이야기가 오면 목표별 선택 칸으로 추가한다(옛 문서는 안 깨짐).

## 손에 든 아이템 가져오기 (에디터 ✋)

- 에디터에서 플레이어를 고르고(브라우저에 기억) 목표·보상 줄의 ✋를 누르면, 서버가 그 플레이어의 **주 손 아이템을 `/give` 문법으로**(`ItemInput.serialize`) 만들어 칸을 채운다. 이름·인챈트·내구도·다른 모드 데이터까지 **전부** 가져온다.
- 목표에 쓸 때는 `damage=…`처럼 원치 않는 부분을 지운다(적힌 것은 모두 맞아야 하므로). 에디터에 이 안내가 있다.
- API: `GET /api/players`, `GET /api/held-item?player=<이름>`. 에디터 포트(8080)처럼 인증이 없다.

## 알아둘 점

- 마인크래프트·모드 버전이 오르면 컴포넌트 문법이 바뀔 수 있다(예: 1.21.5의 이름 표기). 월드 파일이 아니라서 자동 변환을 받지 못한다. 깨지면 publish·로드가 거부하니, 에디터에서 그 줄을 고친다.
- 모드를 빼면 그 모드 아이템을 쓰는 퀘스트 문서 전체가 거부된다(0001: 깨진 문서는 실행하지 않음). 너무 엄하면 "그 퀘스트만 끄기"로 완화할 수 있다(비용 쌈).

## 고르지 않은 것

- **Colophon 전용 칸(`name`, `enchantments`)**: 읽기 쉽고 버전에 강하지만 우리가 만든 칸만 담는다. 다른 모드의 데이터나 "들고 있는 아이템 그대로"를 담을 수 없다.
- **마인크래프트 내부 JSON 형식**: 담는 능력과 버전 약점은 `/give` 문법과 같은데(같은 컴포넌트 변환 규칙을 씀) 사람이 쓰고 읽기 어렵다.
